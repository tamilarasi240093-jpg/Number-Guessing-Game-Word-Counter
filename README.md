# Number Guessing Game & Word Counter

## Project Description
This project contains two Python tools.

### 1. Number Guessing Game
- Generates a random number between 1 and 100.
- Counts the number of attempts.
- Provides a score based on attempts.
- Displays hints like Too High and Too Low.

### 2. Word Counter
- Reads text from a file.
- Counts total words.
- Displays the five most common words.
- Analyzes word frequency.

## Scoring Rule
The player starts with 100 points.
10 points are deducted for every incorrect guess.
The minimum score is 10.
